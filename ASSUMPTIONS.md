# Assumptions

Every non-trivial assumption made while building this. Each one sits behind a single file or config value, so fixing it is cheap.

| ID | Assumption | Why | Depends on it | How to test | If wrong |
|----|-----------|-----|---------------|-------------|----------|
| A-01 | **All photos are placeholders** from Unsplash (free licence), grouped into 9 made-up "shoots". | We don't have Agnes's work yet, and the designs need realistic imagery to be judged. | `content/placeholders.yml`, `pipeline/00-placeholders.mjs`, `content/projects/*/_placeholder_*.jpg` (gitignored) | `npm run eval:content` lists projects that still use placeholders | Drop her images into the project folder, then delete that project's entry in `placeholders.yml` and its `_placeholder_*` files. |
| A-02 | **All project titles, publications and credits are made up.** Only the photographer handles are real (the Unsplash authors). | Same as A-01. Credit text with a realistic length is needed to test the layouts. | `content/projects/*/project.yml` | Eval flags any "Name Surname" left in the credits | Edit the YAML. |
| A-03 | Agnes works between **Paris and Stockholm**. | She studied in Paris and is Swedish. | `content/site.yml: location`, About pages | Ask Agnes | Edit one line. |
| A-04 | Her contact is **agnes@solhall.se** and **@agnessolhall**. | Fits her domain. | `content/site.yml` | Send a test mail. solhall.se needs MX/forwarding for that address. | Edit `site.yml`. If she has an agent, set `agent:`. |
| A-05 | Projects are shown **newest first**. | Common for stylists. | `pipeline/01-content.mjs` sort | Agnes reviews the order | Add `order: 1, 2, …` to project.yml. It overrides the date. |
| A-06 | Image widths are **480/960/1440/2048**, with AVIF q52 + WebP q78. | Covers phones up to 5K retina. Eval shows about 77 KB per AVIF@960 and a 94% saving. | `SETTINGS` in `pipeline/02-images.mjs` | `npm run eval:images` | Change `SETTINGS`. The cache key includes them, so the next build redoes everything. |
| A-07 | The **preview is hosted on GitHub Pages** at `axelsolhall.github.io/fashion_portfolio/`, and production will be **agnes.solhall.se** via a CNAME in Route 53 pointing to `axelsolhall.github.io`. | `solhall.se` is on Route 53 + CloudFront, but this machine has no AWS credentials. Pages is free and deploys from this repo. | `.github/workflows/deploy.yml`, env `SITE_BASE`, `SITE_ROOT_THEME` | Open the URL | To serve from S3/CloudFront like the main domain, only the deploy step changes. Build with `SITE_BASE=/ SITE_ROOT_THEME=<choice>` and sync `dist/`. |
| A-08 | Content is edited as **folders + YAML in git** (by Axel, or by Agnes in GitHub's web UI). | No server, no database, no CMS fees. Every edit is versioned. | `content/` layout, module 1 | Have Agnes add one project herself | Put a git-based CMS (Pages CMS / Decap) on top of the same files. The pipeline doesn't change. |
| A-09 | The site is **English only**. | International fashion industry. | All theme templates | Ask Agnes | Add a `lang` layer to the themes. |
| A-10 | The preview is **noindex** with a "placeholder" note. | Fake credits shouldn't be indexed under her name. | `SITE_PREVIEW` (default on) in `pipeline/03-site.mjs` | View source: `robots` meta | Build with `SITE_PREVIEW=0` at launch. |
| A-11 | Her images are **mostly portrait**. Layouts pair portraits and give landscapes a full row or spread. | Typical for editorial. | `rows()` in `themes/_shared/lib.mjs`, `spreadsOf()` in spread theme | Look at a project with landscapes | Adjust the pairing function in one place per theme. |
| A-12 | **The repo is public**, so her originals will be publicly downloadable from git. | It was already public. GitHub Pages on a free plan needs a public repo. | `content/projects/**` | — | Make the repo private (Pages then needs GitHub Pro) or keep originals out of git and fetch them in CI. |
| A-13 | One credit per role. Multiple names go in one string (`Model: "Name A, Name B"`). | Keeps the YAML simple. | `pipeline/01-content.mjs` credits parsing | — | Allow lists in the parser. |
